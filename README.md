# Hayk Ghazaryan

Systems thinking, expressed in the frontend.

**Now:** workflows where people and coding agents work in the same repository under the same rules, with a human at the gate. Whatever judgment call keeps recurring becomes a lint rule. Daily across Claude Code, Codex, Cursor, Copilot and OpenCode.

**Before that, and still:** monorepos that publish versioned packages so teams release independently; token architectures where components never learn what theme they're wearing; migrations that move a product off a legacy stack while it keeps shipping.

**Three rules I work by:** the best migration is the one nobody notices · if it's an argument twice, it's a lint rule · a memory leak is fixed when the heap stays flat for a hundred cycles and the graph is boring.
